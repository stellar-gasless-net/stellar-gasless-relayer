# Contributing to Stellar Gasless Relayer Service

Thank you for helping build **`stellar-gasless-relayer`**!

## 🛠️ Local Development Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Environment Configuration**:
   ```bash
   cp .env.example .env
   ```

3. **Run Dev Server**:
   ```bash
   npm run dev
   ```

4. **Run Unit Tests**:
   ```bash
   npm test
   ```

---

## 📌 Pull Request Process

- Ensure `npm test` and `npm run build` pass 100% cleanly.
- Use conventional commit messages (`feat: ...`, `fix: ...`, `docs: ...`).
